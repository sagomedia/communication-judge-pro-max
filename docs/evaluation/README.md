# Communicator Judge Pro Max: evaluation design v1

Status: **historical design for review, not a working automation**. Start with the [current project guide](../../README.md) and [measurement plan](../../measurement/progress-v1.md); where this page differs, the newer plan takes precedence. Last researched: 2026-11-03.

## Your first use case

Help you communicate more effectively in English presentations and everyday speaking. Start with a 1–2 minute unscripted explanation to an intended audience. Focus first on making the main point clear, organizing supporting points, and delivering them understandably. English is a starting assumption we can change. A monologue cannot demonstrate conversation skills.

## The intended workflow

1. Provide a recording, prompt, intended audience, objective, and optional self-reported confidence. Retain the original file. Give permission before any outside service receives it.
2. Inspect the recording and produce a timestamped transcript, marking uncertain words. Confirm speaker identity if ambiguous.
3. Assess each eligible criterion independently using the rubric. Find both effective moments and opportunities; cite timestamps and the source modality.
4. Run deterministic checks, then a separate evidence reviewer who can listen to original audio and see video as relevant. Flag contradictions and unresolved items. A matching transcript proves only a text match, not that the audio was correctly transcribed.
5. Produce a short coaching report with per-criterion results, evidence, uncertainty, a prioritized action, and a drill. Save versions and compare only compatible sessions.

A verified observation means its evidence has passed a specified check; it does **not** mean the whole assessment has been validated or professionally certified. The system's custom 1–4 ratings are ordinal coaching labels, not EF SET, CEFR, IELTS, or scientific measurements of confidence. Keep official scores in a separate record.

## Personal defaults to review

- Context: short presentations and everyday explanations; assumed English.
- Useful feedback: one or two strengths, one priority, and a practice task tied to a specific moment.
- Initial target: communicate one main point, two supporting points, and a brief close on two of three comparable fresh practice prompts within four weeks. This is a proposed practice goal, not a proven proficiency standard.
- Confidence: the earlier 1–5 comfort proposal has been superseded by separate 0–10 questions defined in the measurement plan. Do not infer mental state from appearance or audio.
- Visual observations: optional, descriptive and limited to what can actually be seen. They never determine language proficiency.

These are starting preferences, not claims about your current ability. Do not change the rubric or historical scores silently; user-approved changes create a new version.
