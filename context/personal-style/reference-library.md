## Procedure for adding a creator or clip

1. Record creator, exact title, URL, date, format, relevant timestamp and which part the user likes. Confirm identity.
2. State the actual source inspected: original video and audio, transcript only, still frame, or creator description. Watch/listen to the segment before describing visual or vocal delivery. Note if unavailable.
3. Describe a specific behavior and its possible effect, e.g. an example used to explain a term; mark audience impact as a hypothesis unless listener feedback supports it.
4. Translate the behavior into a context-sensitive skill, its evidence requirements, a relevant drill, and a case where the technique would be inappropriate. Do not rate similarity to the creator or require their mannerisms.
5. Add a new candidate rubric/version only with user approval through [calibration](../../workflows/calibrate.md); preserve prior scores. Never use an example as the user's real baseline.
