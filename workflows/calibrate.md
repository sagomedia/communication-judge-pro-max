# Calibrate on user request — manual workflow v1

This corresponds to the video's separate user-invoked calibration workflow. It is not automatic, an installed skill, or a live agent.

1. Record the disputed claim, session, cited media and user feedback; preserve the existing assessment.
2. Replay original evidence if available. State what was mistaken and consider whether it was a one-off error or a general scoring rule issue. Do not conflate ASR mistakes with speech mistakes.
3. Propose a narrowly scoped rule change with rationale, before/after examples and anticipated side effects. Review related cases and, where feasible, a small held-out set; report uncertainty. No retrospective changes unless separately requested.
4. Present the proposed change and impact for the user's explicit approval. With approval, make a new rubric or process version, record it in memory/approved-calibration.md, and preserve the old version. If approval is absent, retain only a proposal in the private session notes.
5. Compare future sessions under the same version. If versions differ, display that fact and do not present the scores as directly comparable without transparent re-review.
