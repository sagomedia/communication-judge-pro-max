# Instructions for work in this project

This project is a personal communication coach. Start with README.md, context/profile.md, context/rubric-v1.md, measurement/progress-v1.md, and the relevant workflow. Distinguish manual instructions from implemented software: do not claim an agent, verifier, scheduler, transcription or measurement has run if it has not.

For evaluation, use workflows/evaluate-session.md. Attribute each factual claim to an available source and time. Treat unreviewed transcripts as fallible and only assess audio/visual qualities when the corresponding media can actually be accessed. Never infer internal confidence, anxiety, personality or intention from video. Use `not assessed` when evidence is insufficient. Do not call custom results EF SET, IELTS, CEFR scores or validated psychological scale scores.

Never overwrite originals or old results. Do not send personal media, transcripts or reports to an external service without the user's explicit authorization. Keep private data under private/ and out of Git; ignore rules are not encryption. Keep other people's consent in mind. Log processing and versions honestly, and do not invent measurements.

Only use memory/approved-calibration.md for rules explicitly approved by the user. workflows/calibrate.md is initiated by the user; do not autonomously change the rubric or history. Notify the user when reports or measurements are uncertain or unverified.
